# MarketHub – Multi-Vendor E-Commerce Marketplace

A modern **Multi-Vendor E-Commerce Marketplace** built using **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Supabase**. The application provides a scalable platform where multiple vendors can manage their products, while customers can browse, search, and purchase products through a responsive user interface.

---

# Project Overview

MarketHub is designed to simplify online marketplace management by allowing multiple vendors to sell products on a single platform. The application uses **Supabase** as the backend service for authentication, database, and data management, while the frontend is built with React and Vite for fast development and high performance.

# Environment Variables

Create a `.env` file in the project root.

Example:

```env
VITE_SUPABASE_URL=your_supabase_project_url

VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Do not upload your `.env` file to GitHub.
