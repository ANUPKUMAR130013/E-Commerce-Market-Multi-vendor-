# 📖 Project Overview

**MarketHub** is a web-based Multi-Vendor E-Commerce Marketplace designed to simplify online buying and selling by providing a centralized platform for vendors, customers, and administrators. Vendors can manage products and inventory, customers can discover and purchase products, and administrators can monitor marketplace activities through a dedicated dashboard.

The application uses **Supabase** for authentication, PostgreSQL database management, and backend services, while **React**, **TypeScript**, **Vite**, and **Tailwind CSS** deliver a modern, fast, and responsive frontend.

# 🔐 Environment Variables

Create a `.env` file in the project root.

```env
VITE_SUPABASE_URL=your_supabase_project_url

VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> **Note:** Never commit your `.env` file or sensitive credentials to GitHub.
